# Notice

## What this repository is

A **review copy** of Bidex, prepared for submission to the **Razorpay
Buildathon**.

It is not the project's repository. The working repository is private and
remains so. This copy exists to be read by the organisers and judges of that
event, for the duration of it.

## What it does not contain

Removed before publication, on purpose:

- development history — this is a single commit, not a history you can walk
- deployment, infrastructure and operations documentation
- the installer and environment bootstrap scripts
- database dumps, schema exports and user exports
- internal engineering notes, design documents and roadmaps
- credentials of every kind; `.env` has never been in version control, and
  `.env.example` lists the shape of the configuration with no values in it

It follows that this copy is readable but not directly runnable. That is
intended.
